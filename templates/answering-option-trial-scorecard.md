# Answering option trial scorecard

Use this to test voicemail, a human answering service, or an AI receptionist on real calls before you sign up for annual pricing. Run one option at a time on the same kind of calls, then compare the bottom lines.

Based on the "fair trial" steps in Peace Call's comparison of AI receptionists, answering services and voicemail:
https://getpeacecall.com/ai-receptionist-vs-answering-service-vs-voicemail/?utm_source=github&utm_medium=social

## 4. Questions to answer before deciding

- [ ] Did urgent calls reach a person fast enough under our own rules?
- [ ] Did the option ever say something we had not approved (prices, diagnosis, promises)?
- [ ] If it records calls, does the greeting cover recording consent for the states we serve?
- [ ] If it is AI, did it say it was a virtual assistant at the start?
- [ ] Did we ask a few callers how it went, where that felt natural?
